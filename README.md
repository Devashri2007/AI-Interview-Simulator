🎯 AI Interview Simulator

An interactive web application that helps users practice job interviews and evaluate their answers.

 ✨ Features

- 👤 Login and signup interface
- 💼 Multiple job roles
- 🎚️ Interview difficulty levels
- ❓ Randomly generated interview questions
- ⏱️ Timer for each question
- 🎤 Voice input support where available
- 📝 Type and submit interview answers
- 📊 Keyword-based answer evaluation
- 📈 Performance dashboard and interview history
- 🔖 Save interview questions
- 🌙 Dark mode
- 🔠 Adjustable text size
- 📥 Export interview history to CSV
- 📱 Responsive user interface

 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

 🚀 How to Run

1. Download or clone this repository.
2. Open index.html in your browser.
3. Choose a job role and difficulty level.
4. Start practicing interview questions.

 🌐 Live Demo

The project can be hosted using GitHub Pages.

⚠️ Note

This is a frontend prototype. Login information is stored locally in the browser, and answer evaluation uses keyword matching rather than a real AI model.
